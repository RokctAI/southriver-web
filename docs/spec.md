**One line:** South River web shell (base_sdk + home SDK, no backend)

## Rationale

Public marketing site for South River, composed with the rokct composer from base_sdk plus a South River home SDK, with no backend calls (blank platform env). Structure follows the aquelle.co.za study of 2026-09-10 (home, about, products, community, news, events, recipes, environment, contact); all copy, imagery and product names are South River's own, none copied from the reference site. Contact via WhatsApp/tel links, static stockists list, no shop. Deploys to Vercel like the other web shells.
